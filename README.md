# DNS Security Basics

## Overview
This project covers DNS resolution, DNS spoofing, DNSSEC, and basic DNS security measures.

## Objectives
- Understand DNS resolution.
- Identify common DNS security risks.
- Learn how DNSSEC protects DNS data.

## Approach
This project explains DNS resolution, DNS spoofing, and DNSSEC through conceptual analysis.

## Security Measures
- Use trusted DNS resolvers.
- Enable DNSSEC validation where supported.
- Keep DNS software updated.
- Monitor DNS configuration changes.

## Configuration
A sample DNS resolver configuration is provided for educational purposes. It has not been deployed to a live server.

## Rollback
A rollback procedure is documented for reference. No live deployment or rollback was performed.

## Outcome
The project explains basic DNS security risks and preventive measures.
